## 🎨 Design System: "Maison Archive"

The application follows a strict design philosophy to ensure a feeling of "heavy" luxury and kinetic responsiveness.

*   **Typography**:
    *   **Syncopate**: Primary headers and architectural labels. Used for impact.
    *   **Outfit/Plus Jakarta Sans**: Body text and highly readable data points.
*   **Palette**:
    *   `Luxury Gold` (#D4AF37): Accents, active states, and premium indicators.
    *   `Obsidian` (#050505): Deep backgrounds for infinite depth.
    *   `Cream`: Soft text for optimal reading comfort.
*   **Kinetic UI**:
    *   **Glassmorphism**: Multi-layered blurs for depth.
    *   **Micro-interactions**: Subtle hover glimmers, magnetic buttons, and smooth layout transitions (Framer Motion).
    *   **Noise Overlays**: Film grain textures to reduce digital sterility.

## 🛠 Technology Stack

*   **Core**: React (Vite), TypeScript

*   **Motion**: Framer Motion.
*   **Backend**: Supabase (Database, Auth, Edge Functions, RLS).
*   **Rendering**: HTML-to-Image / jsPDF for document generation.
